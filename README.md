## Reposição Essencial

Uma **calculadora gratuita de ponto de reposição de estoque** para pequenos negócios. Funciona diretamente no navegador e não exige instalar Node.js, criar conta ou enviar os valores digitados para o servidor pelo código da calculadora.

**[Usar a calculadora gratuita e consultar os guias](https://reposicao-essencial-denys.totalsage5.chatgpt.site/)**

Os conteúdos disponíveis incluem um tutorial, checklist e guias sobre controle de estoque e a diferença entre estoque mínimo e ponto de reposição:

- [Tutorial: como calcular o ponto de reposição](https://reposicao-essencial-denys.totalsage5.chatgpt.site/tutorial-reposicao)
- [Checklist gratuito antes de repor](https://reposicao-essencial-denys.totalsage5.chatgpt.site/checklist-reposicao)
- [Controle de estoque para pequenos negócios](https://reposicao-essencial-denys.totalsage5.chatgpt.site/controle-estoque-pequeno-negocio)
- [Estoque mínimo x ponto de reposição](https://reposicao-essencial-denys.totalsage5.chatgpt.site/estoque-minimo-ponto-reposicao)

### Exemplo rápido

Com demanda diária de **3 unidades**, prazo de reposição de **5 dias** e estoque de segurança de **6 unidades**, o ponto de reposição é **21 unidades**. Se o estoque projetado for **14 unidades**, a quantidade indicada para **revisão humana** é **7 unidades**, não uma compra automática.

Veja também o [guia rápido com os limites da fórmula](docs/guia-rapido-ponto-reposicao.md).
