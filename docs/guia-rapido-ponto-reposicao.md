# Como calcular o ponto de reposição de estoque

Para pequenos negócios, o ponto de reposição é uma **referência de quando revisar uma possível compra**, não uma ordem automática.

**Fórmula inicial:** `ponto de reposição = demanda diária × prazo de reposição em dias + estoque de segurança`.

## Exemplo fictício

Suponha demanda média de **3 unidades por dia**, prazo de entrega de **5 dias** e estoque de segurança de **6 unidades**:

- Ponto de reposição: `3 × 5 + 6 = 21` unidades.
- Estoque disponível: `10` unidades.
- Entradas previstas que chegarão a tempo: `4` unidades.
- Estoque projetado: `10 + 4 = 14`.
- Quantidade para revisão: `max(0, 21 - 14) = 7` unidades.

A quantidade de **7** precisa ser analisada antes de qualquer compra. Se a entrega atrasar, o prazo deve ser revisto; se a demanda variar, uma média fixa pode enganar.

## Antes de decidir

1. Verifique se o prazo previsto pelo fornecedor é realista.
2. Não conte entradas que só chegarão depois do período considerado.
3. Revise sazonalidade, promoções e possíveis mudanças de demanda.
4. Compare validade, espaço disponível, lote mínimo e orçamento.
